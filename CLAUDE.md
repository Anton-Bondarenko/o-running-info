# Инструкции для AI-агента (Claude Code)

## О проекте
Веб-приложение для тренера по бегу. Позволяет вести учет спортсменов, сроков действия медицинских допусков, статуса РУСАДА и ежемесячного бегового объема. Целевая платформа: Raspberry Pi 4 (ARM64).

## Технологический стек
- **Язык:** Python 3.11+
- **Фреймворк:** FastAPI + Uvicorn
- **База данных:** SQLite + SQLAlchemy (асинхронный или синхронный режим, предпочтительно синхронный для простоты)
- **Шаблоны и фронтенд:** Jinja2, HTMX (через CDN), Tailwind CSS (через CDN)
- **Тестирование:** pytest, httpx

## Правила разработки
1. **Минимум файлов:** Не усложняй архитектуру. Избегай лишних абстракций (репозиториев, фабрик).
2. **Самопроверка:** После написания кода каждого этапа обязательно запускай `pytest` и проверяй работоспособность эндпоинтов через `TestClient` или `curl`.
3. **Фронтенд без сборки:** Не используй npm, Node.js, React или Vue. Весь JS/CSS подключается через `<script>` и `<link>` в базовом HTML-шаблоне.
4. **Чистота кода:** Всегда добавляй type hints в Python. Обрабатывай пустые значения (None) в датах и километраже.
5. **Безопасность и изоляция HTML в именах:** Поле `full_name` поддерживает пользовательскую HTML-разметку (теги цвета, шрифтов, начертания) и эмодзи. Очищай ввод через библиотеку `bleach` (разрешая только безопасные теги оформления и блокируя `<script>`, `<iframe>`, `onload` и т.д.), а при выводе в таблицу оборачивай имя в изолированный CSS-контейнер.
6. **Не используй фоновых агентов**
7. **Всегда доказывай что баг исправлен, если это UI, то скриншот**
